# ぐらぐらラボ 🧸

4歳児向けの地震・防災物理ゲーム。
くまのぬいぐるみを部屋の好きな場所に置いて地震を起こし、**時間を巻き戻して、条件をひとつだけ変えて、まったく同じ地震をもう一度**体験します。

「机のそばでは本が落ちてくる場所とくまの場所が重なる」「机の下では天板が本を受け止めてくれる」——この違いを、説明ではなく物理挙動の比較から体感するゲームです。

## 4つの部屋と学び

| 部屋 | 体感できること |
|---|---|
| こども部屋 | 本棚の絵本が降ってくる。**机の下では天板が受け止めてくれる** |
| 寝室 | 壁棚の本がベッドに落ちてくる。**ベッドの上では布団がふわっと受け止めてくれる**。つよい揺れではタンスが倒れる |
| リビング | テレビが台から滑り落ち、つよい揺れでは飾り棚が倒れる。**なにもない部屋の真ん中がいちばん安全**。棚をタップすると**金具（ピンクのベルト）**が付き、同じ揺れでも倒れなくなる |
| キッチン | 食器棚の前は木のお皿の雨（割れない・火や刃物は無い）。**テーブルの下は安全** |

さらに、**揺れの強さを3段階**から選べます（ぐらぐらボタン横の波チップ）：

- 〜 よわい：高い所の物だけ落ちる
- ≈ ふつう：本やライト、お皿が落ちる
- ≋ つよい：**ゆっくり大きい揺れ**になり、背の高い家具が倒れる（長周期ほど背の高い物が倒れやすいという、実際の地震と同じ性質）

## 起動方法

```bash
cd guragura-lab
npm install
npm run dev        # http://localhost:5173 をブラウザで開く
```

iPad / iPhone で遊ぶ場合は、同じネットワークから `npm run dev -- --host` で表示されるNetworkアドレスを開いてください。縦画面・横画面の両方に対応しています。

```bash
npm run build      # dist/ に静的ファイルを出力（そのまま配信可能）
npm test           # Playwright による自動テスト（フロー・決定論・各部屋の学び）
node scripts/sim-check.mjs kids 13 1      # 部屋・シード・強さ別の物理をCLIで確認
node scripts/sim-check.mjs sweep 13       # 全部屋×全強さ×金具の要約
```

## 遊び方（文字なしで遊べます）

1. ✋ 光る輪のついた**くま**をドラッグして好きな場所へ置く（ベッドやソファ、クッションの上にも乗れる）
2. ◀▶ 画面横の矢印で部屋を移動、波チップで揺れの強さを選ぶ
3. 🏠 ピンクの大きな**ぐらぐらボタン**を押す
4. 部屋が4〜6秒揺れて、物が落ち、崩れ、（つよい揺れなら）家具が倒れる
   - 落ちる物には**光の軌跡**、落下地点には**オレンジの危険の影**が予告表示
   - くまの近くに落ちる/倒れてくる瞬間は**スローモーション**（ぶつかる絵は見せない）
   - 家具は**ゆっくり「ぽふん」**と倒れる（怖い音・破壊表現なし）
5. 結果バッジ：☀️安全／⚠️あぶなかった／🛡️机・テーブルが守ってくれた／🛏️布団が守ってくれた
6. 🔵 青いボタンで時間が巻き戻る
7. **条件をひとつだけ変える**：くまの場所を変える、または（リビング・寝室では）家具をタップして金具を付ける
8. もう一度ぐらぐらボタン → **まったく同じ揺れ**が再現され、前回のくまの半透明ゴーストと落下地点リングが重なって表示される
9. 画面上部にAとBの結果が並び、「変えた条件だけで結果が変わった」ことがわかる

右上のメニュー（●●●）から 🎲（別の揺れパターン）と 🏠（はじめから）を選べます。

## 設計方針

### 1. 「同じ揺れ」の決定論（このゲームの核心）

- **シード付き乱数**（mulberry32）から地震波形（加速度・変位・タイミング）を全ステップ分事前生成します。強さは波形の振幅と周波数スケールだけを変え、同じシード＋同じ強さなら波形は毎回ビット単位で同一です（`src/core/quake.js`）。
- **固定タイムステップ**（1/120秒）で cannon-es の物理を回します（`src/core/simulate.js`）。
- 「ぐらぐら」ボタンを押した瞬間に**地震の全過程を一括計算**し、全オブジェクトの軌道・衝突・着地点・転倒イベントを記録（Recording）します。画面はこの記録を再生するだけなので、フレームレートやスローモーションに関係なく、AとBの物の動きは**厳密に一致**します。記録は（部屋・シード・強さ・金具）の組でキャッシュされます。
- **くまは物理世界に存在しません**。物はくまをすり抜け、くまの安全・危険は「記録された軌道とくまの位置の重なり」から後判定します（`findDangerEvents`）。これにより「くまの位置だけを変えて、同じ地震」が構造的に保証され、ぬいぐるみに物が直撃して痛そうに見える映像も原理的に発生しません。
- シールド（机の天板・テーブル・布団）はデータ定義です：くまがシールドのゾーン内にいるとき、シールド面より上にある物は危険判定から除外されます。
- **転倒家具**は重い動的ボディとして物理に参加し、**金具ON**では静的ボディに変わるため、同じ波形でも倒れません。転倒中の家具とくまの重なりは向き付きボックス（OBB）で判定します。

### 2. 幼児向け表現

- 危険は「オレンジの危険の影」「半透明のくまの輪郭」「落下軌道の光」「衝突直前のスローモーション」で表現し、負傷・HP・ゲームオーバー・悲鳴・火災・崩壊・ガラス片・刃物・本物の緊急地震速報音は一切使いません。
- キッチンのお皿は木製で、割れずに転がるだけ。コンロや包丁はそもそも置いていません。
- 家具の転倒はスローモーション＋低くやわらかい「ぽふん」音＋ピンクの星で表現します。
- 音はすべて Web Audio でその場で合成。音声ファイルはありません。ミュートボタンあり。
- 文字は一切表示しません。状態はボタンの色と絵、バッジの絵で伝えます。
- **UI（DOMレイヤー）とカメラは地震中も揺れません**。揺れの変位は3Dシーンのルートグループにだけかかります。

### 3. 物理エンジンの注意点（cannon-es）

cannon-es の摩擦は「1ステップあたりの力積」を直接制限するため、接触点の多い平たい物は事実上滑りません。本作では：

- 本・積み木・家具は**転倒（ロッキング）**で動く前提でレイアウトしています。
- お皿・マグなど滑らせたい物には極小μの専用マテリアル（`slick`）を使い、食器棚の棚板を**わずかに前傾**させることで、振動の対称性を破って前へ滑り出すようにしています（`src/core/simulate.js` のコメント参照）。
- こうした調整はすべて `scripts/sim-check.mjs` でブラウザなしに検証できます（決定論のビット一致チェック付き）。

## 次に追加しやすい機能

- **もっと部屋**：`core/rooms/` に RoomDef を1つ足し、`scene/rooms/` に家具ビジュアルを書いて registry に並べるだけ。物理・判定・UI はすべて共通コードが処理します。
- **金具の種類**：突っ張り棒・滑り止めマットなど。`simulate.js` の anchors 分岐に対策別の物理変化を足せば、そのまま比較実験になります。
- **おかたづけモード**：揺れのあとに散らばった物をドラッグで元に戻す遊び。RoomDef の初期位置がそのまま「正解」です。
- **リプレイ保存**：部屋・シード・強さ・金具・くまの位置の5つを保存すれば完全再現できます。
- **くまの友だち**：2体目のぬいぐるみで同時比較（危険判定はくまごとに独立計算可能）。
- **ならべて比較モード**：A/Bの記録を2つの小部屋で同時再生（Recording は独立再生できる構造です）。
