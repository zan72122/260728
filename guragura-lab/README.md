# ぐらぐらラボ 🧸

4歳児向けの地震・防災物理ゲーム。
くまのぬいぐるみを部屋の好きな場所に置いて地震を起こし、**時間を巻き戻して、くまの場所だけを変えて、まったく同じ地震をもう一度**体験します。

「机のそばでは本が落ちてくる場所とくまの場所が重なる」「机の下では天板が本を受け止めてくれる」——この違いを、説明ではなく物理挙動の比較から体感するゲームです。

## 起動方法

```bash
cd guragura-lab
npm install
npm run dev        # http://localhost:5173 をブラウザで開く
```

iPad / iPhone で遊ぶ場合は、同じネットワークから `npm run dev -- --host` で表示されるNetworkアドレスを開いてください。縦画面・横画面の両方に対応しています。

```bash
npm run build      # dist/ に静的ファイルを出力（そのまま配信可能）
npm test           # Playwright による自動テスト（フロー・決定論の検証）
node scripts/sim-check.mjs 13   # ブラウザなしで物理挙動・決定論を確認
```

## 遊び方（文字なしで遊べます）

1. ✋ 光る輪のついた**くま**をドラッグして好きな場所へ置く
2. 🏠 ピンクの大きな**ぐらぐらボタン**を押す
3. 部屋が4〜6秒揺れ、本棚の絵本や卓上ライトが落ち、積み木が崩れる
   - 落ちる物には**光の軌跡**、落下地点には**オレンジの危険の影**
   - くまの近くに落ちる瞬間は**スローモーション**（ぶつかる絵は見せない）
4. ☀️/⚠️ 結果バッジが出る（にこにこ太陽＝安全、オレンジの雲＝あぶなかった、机＋ハート＝机が守ってくれた）
5. 🔵 青い**巻き戻しボタン**で時間が巻き戻る
6. くまを**別の場所**へ動かす（前にいた場所には青い半透明のくまと着地リングが残る）
7. もう一度ぐらぐらボタン → **まったく同じ揺れ**が再現される
8. 画面上部にAとBの結果が並び、場所の違いだけで結果が変わったことがわかる

右上のメニュー（●●●）から 🎲（別の揺れパターン）と 🏠（はじめから）を選べます。

## 設計方針

### 1. 「同じ揺れ」の決定論（このゲームの核心）

- **シード付き乱数**（mulberry32）から地震波形（加速度・変位・タイミング）を全ステップ分事前生成します。同じシードなら波形は毎回ビット単位で同一です（`src/core/quake.js`）。
- **固定タイムステップ**（1/120秒）で cannon-es の物理を回します（`src/core/simulate.js`）。
- 「ぐらぐら」ボタンを押した瞬間に**地震の全過程を一括計算**し、全オブジェクトの軌道・衝突・着地点を記録（Recording）します。画面はこの記録を再生するだけなので、フレームレートやスローモーションに関係なく、AとBの物の動きは**厳密に一致**します。
- **くまは物理世界に存在しません**。物はくまをすり抜け、くまの安全・危険は「記録された軌道とくまの位置の重なり」から後判定します（`findDangerEvents`）。これにより「くまの位置だけを変えて、同じ地震」が構造的に保証され、ぬいぐるみに物が直撃して痛そうに見える映像も原理的に発生しません。
- くまが机の下にいる場合、天板より上にある物は危険判定から除外されます（天板が守るという事実を判定にも反映）。

### 2. 幼児向け表現

- 危険は「オレンジの危険の影」「半透明のくまの輪郭」「落下軌道の光」「衝突直前のスローモーション」で表現し、負傷・HP・ゲームオーバー・悲鳴・火災・崩壊・ガラス片・本物の緊急地震速報音は一切使いません。
- 音はすべて Web Audio でその場で合成（低いゴトゴト・ぽとん・ぽよん・キラキラ・ファンファーレ）。音声ファイルはありません。
- 文字は一切表示しません。状態はボタンの色と絵、バッジの絵で伝えます。
- **UI（DOMレイヤー）とカメラは地震中も揺れません**。揺れの変位は3Dシーンのルートグループにだけ適用されます。

### 3. レイアウト調整と検証

家具の配置・摩擦・本の置き方（絵本の面出し収納）は、`scripts/sim-check.mjs` でブラウザなしに着地点と安全判定を確認しながら調整しています。同スクリプトは同一シードの2回実行がビット単位で一致することも検証します。

## 次に追加しやすい機能

- **べつの部屋**：`layout.js` を部屋ごとのモジュールに分ければ、キッチン・リビングなどを追加できます（家具スペックの配列を差し替えるだけ）。
- **家具の固定金具モード**：本棚に「金具」を付けると倒れない・本が滑りにくくなる比較実験。`simulate.js` の摩擦・拘束を切り替えてシードを固定すれば、そのまま A/B 比較になります。
- **揺れの強さ選択**：`quake.js` の `peakAccel` と包絡線をプリセット化（よわい・つよい）。
- **おかたづけモード**：揺れのあとに散らばった物をドラッグで元に戻す遊び。`layout.js` の初期位置がそのまま「正解」になります。
- **リプレイ保存**：Recording は素の TypedArray なので、シードとくまの位置だけ保存すれば完全再現できます。
- **くまの友だち**：2体目のぬいぐるみを置いて同時比較（危険判定はくまごとに独立して計算可能）。

## 技術スタック

Three.js（描画）/ cannon-es（物理）/ Vite（ビルド）/ Playwright（テスト）。外部アセットなし——すべての見た目はコードとCanvasテクスチャで生成しています。
