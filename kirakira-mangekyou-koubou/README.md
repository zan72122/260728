# ✦ きらきら まんげきょう こうぼう ✦

4さいのおこさま向けの「万華鏡（まんげきょう）を **つくって・のぞいて・まわして** あそぶ」Webゲームです。
iPad / iPhone の Safari で、縦画面でも横画面でもあそべます。

![対象] 4歳〜 ／ ![端末] iPad・iPhone（PCブラウザでも動作） ／ ![通信] 不要（完全ローカル動作・外部アセットなし）

---

## あそびかた

### 1. こうぼうで つくる
- **かがみを えらぶ** … 2まい／3まい／4まい。枚数で模様の細かさが変わり、上のプレビューにすぐ反映されます。
- **かがみを ちょっと ずらす** … スライダーで鏡の角度に「ずれ」を入れられます。ずらすと模様の継ぎ目が破れて、星がつぶれたり左右がずれたり——その不完全さがおもしろい。
- **なかみを いれる** … びんをタップすると、びーず・きらきら（ラメ）・はなびら・おほしさまが上からパラパラ落ちてきます（ながおしで連続投入）。入れすぎると「もういっぱい！」。
- **おみずを いれる** … 中がとろとろの液体になり、ラメはただよい、あわが浮かびます。
- **からっぽに する** … ぜんぶ出してやりなおし。

### 2. のぞいて まわす
- **ゆびで くるくる** … 画面をなぞると筒が回り、中身がころころ転がって模様が生まれ変わります。はなして惰性でゆっくり回るのも本物どおり。
- **かたむける** … iPhone/iPad を傾けると重力の向きが変わり、中身がざあっと流れます（初回に「かたむき」ボタンでセンサーを許可）。本体をシェイクすると中身が飛び散ります。
- **なかみを かえる** … のぞいたまま下のトレイから素材を追加したり、おみず・かがみの枚数を切り替えたり。原因→結果をその場で確かめられます。
- **しゃしん** … いまの模様を1枚の絵にして保存できます。

つくったレシピは自動保存され、次にひらいたとき続きからあそべます。

## うごかしかた

ただの静的サイトです。フォルダごと配信するだけ：

```bash
cd kirakira-mangekyou-koubou
python3 -m http.server 8000
# → http://localhost:8000 を Safari/Chrome でひらく
```

※ かたむきセンサー（DeviceOrientation）は **HTTPS または localhost** でのみ動作します。
※ `index.html` をファイルとして直接ひらいても、センサー以外はすべて動きます。

## つくりのポイント（技術メモ）

すべて素の HTML / CSS / JavaScript（Canvas 2D + WebAudio）。ビルド不要・依存ゼロ。

### 本物の万華鏡としくみを揃えた描画
- **鏡映行列の積み重ね** … となり合うセクターは「共有する辺（＝鏡の線）に対する鏡映」。2×2 の反射行列を辺ごとに掛け重ねて描くので、鏡が完璧なら模様はぴったり連続します。
- **「ずらし」は角度誤差の蓄積** … スライダーは1セクターあたり最大±3.2°の誤差を足すだけ。誤差が一周ぶん積もった場所に自然な「破れ目」が現れます（つくりものの乱数ではなく、幾何学的に正しい崩れかた）。
- **鏡のくさびは「なかみのたまり」を覗く** … 実物のブリュースター式と同じく、視線の頂点はセルの中心ではなく中身の重心側にオフセット。セルの壁（ガラスのふち）が模様の中に弧として写り込みます。
- **視線の重心追尾** … 速く回すと中身は遠心力で壁に張りつき、重力から遅れて回ります。視線が中身の重心をなめらかに追うので、どう乱暴に回しても「なにも見えない」瞬間がありません。

### 物理シミュレーション（筒に固定した座標系）
- 筒を回すと**重力ベクトルのほうが回る**方式。回し始め・止めた瞬間のオイラー力、回しつづけたときの遠心力も入っていて、「中身が遅れてついてくる」「回すと外に寄る」が再現されます。
- 素材ごとに反発・抵抗・比重が違います：びーずはカチカチ跳ね、はなびらはひらひら落ち、ラメは水中でほぼ漂う。
- おみずモードでは粘性が上がり、あわが重力の逆向きに立ちのぼり、筒の回転に引きずられた渦ができます。

### 描き込み
- 粒はすべて事前レンダリングしたスプライト：ガラスびーずは底色→透過光→映り込み→二重ハイライトの4層、ラメはホログラム六角、おほしさまは金平糖風のぷっくり、はなびらは切れ込み・葉脈・ふちの光つき。
- ラメは向きによって明滅し、光る角度を通った粒には十字フレアが立ちます。
- すりガラス越しの光、ゆっくり動く光斑（コースティック）、縮小→拡大のソフトブルーム、プリズム色のリム、筒内面のハイライトが回転に追随。

### 音（全部その場で合成・音声ファイルなし）
- オルゴール風の生成BGM（ペンタトニックなので同じ曲になりません）
- びーずが壁に当たる「カチッ」（速度と粒の大きさでピッチが変わる・鳴りすぎ抑制つき）
- 素材ごとに違う「そそぐ音」、のぞいた瞬間のグリッサンド、シャッター音 など

### 4さい向けの配慮
- 文字はぜんぶひらがな・タップ対象は48px以上・誤操作しやすいピンチズームやダブルタップズームは無効化
- はじめてのぞいたときだけ「ゆびで くるくる まわしてね」の手のコーチが出ます
- 何も入れずに「のぞく」を押しても、そっとひとすくい入れてあげます
