# ✦ きらきら まんげきょう こうぼう ✦

4さいのおこさま向けの、万華鏡（まんげきょう）を **調律（ちょうりつ）して・のぞいて・まわして** あそぶ Webゲームです。
「素材を入れるだけ」ではなく、**対称性・光・物体の運動・不完全さを自分でいじる「光学装置の工房」**になっています。
iPad / iPhone の Safari で、縦画面でも横画面でもあそべます。

対象: 4歳〜 ／ 端末: iPad・iPhone（PCブラウザでも動作） ／ 通信: 不要（完全ローカル動作・外部アセットなし）

---

## あそびかた（ワンワールドUI）

画面はひとつだけ。起動したら**いつも全画面の万華鏡をのぞいていて**、
指でくるくる回すのも、端末をかたむけるのも、常に効きます。

画面下の「どうぐばこ」を押すと半透明のドックがスライドインし、
部品を差し替えた瞬間、背後の世界がその場で変わります。画面遷移はありません。

**文字はどこにもありません。** 4歳児は文字が読めないので、
選択肢は「結果で選ぶカタログ」——かがみ・せいかく・ひかり・のぞきあな・レンズは、
その部品にした場合の“実際のいまの模様”がライブで映る小さな丸窓です。
名前ではなく見た目で選びます。はじめてだけカテゴリが順番に光って誘導します。

かけ算すると 7,000 通り以上。でも子どもから見えるのは「カードを差すだけ」です。
ズレも曇りも片寄りも失敗ではなく、その万華鏡の**性格**として楽しめます。

### あそびの操作
- **ゆびで くるくる** … 筒が回り、中身が転がって模様が生まれ変わる。離せば惰性でゆっくり回る
- **かたむける / ふる** … 実機では重力の向きが変わって中身が流れ、シェイクで飛び散る（初回に「かたむき」ボタンで許可）
- **しゃしん** … いまの模様を1枚の絵にして保存（ボタンはすべてアイコンのみ）

レシピは自動保存され、次にひらいたとき続きからあそべます。

## うごかしかた

ただの静的サイトです。フォルダごと配信するだけ:

```bash
cd kirakira-mangekyou-koubou
python3 -m http.server 8000
# → http://localhost:8000 を Safari/Chrome でひらく
```

※ かたむきセンサー（DeviceOrientation）は **HTTPS または localhost** でのみ動作します。
※ `index.html` を直接ひらいても、センサー以外はすべて動きます。

## つくりのポイント（技術メモ）

すべて素の HTML / CSS / JavaScript（Canvas 2D + WebAudio）。ビルド不要・依存ゼロ。

### 本物の万華鏡と同じしくみの描画
- **鏡映行列の積み重ね** … となり合うセクターは「共有する辺（＝鏡の線）に対する鏡映」。2×2 反射行列を辺ごとに掛け重ねるので、鏡が完璧なら模様はぴったり連続する
- **反射回数ごとの減衰と色寄り** … 各セクターの反射回数 n に対して RGB 別の残存率 keepRGB^n を乗算合成。安い鏡ほど奥が暗く沈み、こおり鏡は青へ、おうかん鏡は金へ寄っていく——本物の鏡の物理
- **「ずらし」は角度誤差の蓄積** … スライダーは1セクターあたり最大±3.2°の誤差を足すだけ。誤差が一周ぶん積もった場所に自然な破れ目が現れる
- **鏡のくさびは「なかみのたまり」を覗く** … 実物のブリュースター式と同じく、視線の頂点はセル中心ではなく中身の重心側にオフセット。セルの壁が模様の中に弧として写り込む
- **視線の重心追尾** … 速く回すと中身は遠心力で壁に張りつき重力から遅れて回る。視線が中身の重心をなめらかに追うので、どう乱暴に回しても「なにも見えない」瞬間がない
- **平行鏡モード** … 上下鏡映を Ty(kH)∘My^k で積み、奥の帯ほど減衰する無限廊下。ずらすと廊下が扇形にひらいて壊れる

### 鏡の性格の実装
| せいかく | 実装 |
|---|---|
| ふわふわ | セクター内容を微回転させた二重像を重ね描き |
| ゆめ | チャンバーを縮小→拡大してとろけさせ、白をまとわせる |
| きらり | 鏡の線に沿って明滅するキズの光線（lighter 合成） |
| ぐにゃ | チャンバーを横帯スライスして正弦波でずらす波打ち曲面 |
| おばけ | 反射像を薄め、鏡を透過した素のなかみをずらして重ねる |

### 「じぶんの手で世界を変えた」を最大化する入力増幅
- **おえかきスタンプこうぼう** … パッドの隣にライブの万華鏡プレビューがあり、1画ごとに線が鏡のまい数ぶん増えていく（入力増幅が「見えながら」起こる）。パッド自体にも「かがみペン」で6回対称をかけられ、ぐちゃぐちゃ描きが一瞬でちょうちょや雪の結晶になる。クレヨン6色＋にじいろペン＋きらきらペン（十字フレアを散らす）
- **自動ステッカー化パイプライン** … 余白トリミング→画面いっぱいに拡大→彩度ブースト→白いステッカーふち（シルエットを16方向に重ねる）→やわらか影→ガラスの照り。黒い線1本でも「白ふちの宝物」になり、大1・中2・小2の5枚に増殖して筒に注がれる
- **しゃしんのステンドグラス** … 写真は粒ではなくセルの背面光になる（粒だと鏡が写真を細切れにして判別不能になるため）。64×64解析でエッジ密度と彩度マップを計算し、細かすぎる写真はカラフルな領域へ自動ズーム、暗い写真は明るさを自動補正。ひかりのフタは乗算合成で写真に色を乗せる（よるのひかり＝夜の写真になる）。写真モード中はくさびの頂点を写真の中心近くへ移し、中央の被写体が映るようにする。高彩度スポットから丸/星/ハートで打ち抜いたチップが粒として舞い、投入時は写真が主役になるよう他の中身を自動で空にする。すべて端末内処理・アップロードなし
- つくったものは「つくったもの棚」に残り、タップでもう一度注げる。レシピと一緒に保存され次回も復元

### 物理シミュレーション（筒に固定した座標系）
- 筒を回すと**重力ベクトルのほうが回る**方式。オイラー力・遠心力入りで「中身が遅れてつく」「回すと外に寄る」が出る
- **つつの断面形は符号付き距離場（SDF）**で表現。丸・角丸四角・楕円・星形（5つのくぼみ）それぞれの壁で衝突・滞留・雪崩の挙動が変わる
- 素材ごとの反発・抵抗・比重。おみずモードは粘性・あわ・筒回転に引きずられる渦

### 描き込み・音
- 粒はすべて事前レンダリングしたスプライト（ガラスびーず4層の光・ホログラムラメ・金平糖の星・葉脈つき花びら）
- ラメは向きで明滅し、光る角度で十字フレア。よるのひかりでは閾値が下がって星空になる
- コースティック光斑・ソフトブルーム・プリズム色のリム・のぞきあな形状のふち金具
- 音は全部その場で合成: 生成オルゴールBGM・粒の大きさでピッチが変わる衝突音（角ばった筒は低い「コトン」）・素材別の注ぐ音・部品が「カチッ」とはまる音

### 4さい向けの配慮
- 文字はぜんぶひらがな・数値は一切見せない（内部の約40変数はカードに圧縮）
- タップ対象は44px以上・ピンチ/ダブルタップズーム無効化・縦横両対応
- はじめては組み立て順ガイド、はじめてのぞくときだけ「くるくる」コーチ
- 空っぽで「のぞく」を押しても、そっとひとすくい入れてあげる
