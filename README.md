# 浸水シミュレーション 3D Webアプリ

大雨で住宅(1階1部屋1ドア)の周囲が**完全に水没**した状況で、
「ドアを開けたら何が起きるか」を体験できる防災シミュレーションです。
iPhone / iPad のブラウザ(縦・横画面)での利用を想定しています。

## 体験できること

- **ドアの開け方で水の入り方が変わる**
  ドアノブをスワイプすると、指の速さ・距離のとおりにドアが動きます。
  ゆっくり少しだけ開ければ緩やかな流入、勢いよく開ければ激流になります。
  内開きドアのため、ある程度開くと**外の水圧で一気に押し開けられます**。
- **物の状態によって挙動が変わる**
  スリッパやクッションはすぐ浮き、椅子やテーブルは水位が上がると浮いて流され、
  タンスは水を含んでほぼ沈んだまま、冷蔵庫は深水で浮き上がって転倒し、
  吊り下げ照明は吊り下がったまま揺れ、本棚の本は水位が届くと浮き出します。
- **主人公(一般成人)の状態遷移**
  浅いうちは歩けますが、水深が増すと滑り・よろけが起き、
  胸の高さを超えると浮いて泳ぎに移行します(上手く泳げる想定)。
  満水間際は天井直下に残る空気層で立ち泳ぎになります。
- **リセット**アイコン(0.6秒ホールド)でいつでも初期状態に戻し、
  開け方を変えて何度も比較できます。

## 操作(文字なし・アイコン最小)

| 操作 | 動作 |
|---|---|
| ドアノブをスワイプ | ドアの開閉(速さ・距離がそのまま反映) |
| 画面左半分をドラッグ | 移動ジョイスティック(タッチ位置に出現) |
| 画面右半分をドラッグ | カメラ回転(泳ぎ中は縦方向が潜行/浮上) |
| 2本指ピンチ | ズーム |
| ⟲ 長押し | リセット |
| ≡ | メニュー(描画品質切替・ヘルプ) |

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # ビルド
npm test         # Playwright による決定的シミュレーション検証+スクリーンショット
```

技術: Three.js + TypeScript + Vite + Rapier(@dimforge/rapier3d-compat)+
postprocessing/n8ao(SSAO・ブルーム・ビネット。メニューの品質切替でオフ可能)。
テクスチャ(法線マップ含む)・環境マップはすべて Canvas によるプロシージャル生成で、外部アセットはありません。
部屋の外から見たときは壁が透けて水槽のように浸水状況を観察できます(壁掛け物は
カメラがその壁の外にあるとき自動で非表示)。視界を塞ぐ大型家具は自動で半透明になります。
`?test=1` を付けると `window.__sim`(固定ステップ手動進行・状態取得)が公開され、
決定的なテストができます。
