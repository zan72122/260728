# スルッ！ピカッ！おなかのガレージ

4歳児向けの自動車修理ブラウザゲーム（iPhone / iPad、縦横両対応）。
文章を読まなくても、光・音・視線・矢印のヒントだけで一周遊べます。

## 遊び方（基本ループ）

1. ガタガタ音のする車が入庫
2. レバーを上へスワイプ → リフト上昇、安全ロックが「カチッ」
3. スワイプでクリーパーに乗った整備ロボが車の下へスルッ
4. ゆるんだボルト（トントン締める）／外れたクリップ（はめる）／
   抜けたホース（つなぐと冷却液が流れる）／ガタガタ排気管（押し上げる）を修理
5. スワイプで外へスルッと出る
6. 溶接マスクをタップして構える
7. 車体の裂け目を指でなぞると青白いアーク光が走り、銀色の溶接ビードが残る
8. レバーを下へスワイプ → テストコースで直ったことを確認
9. 「もういっかい」「つぎのくるま」「じゆうにあそぶ」から選ぶ

車は3台（故障の組み合わせと溶接箇所が異なる）、テストコースは2種類。
フリーモードでは鋼板への溶接お絵かき、クリーパーの出入り、
リフト操作、テスト走行が自由にできます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # TypeScript 型検査
npm run build      # 本番ビルド (dist/)
npm run preview    # dist/ を http://127.0.0.1:4173 で配信
npm run e2e        # Playwright による自動一周プレイ検証（要 preview 起動）
                   # iPhone/iPad 縦横で全フェーズを操作し shots/ に記録
```

技術: Vite + TypeScript + Three.js (WebGL) のフル3D +
画面スペース演出用の2Dオーバーレイキャンバス。音はすべて WebAudio で
合成（音源ファイルなし）。画面回転してもカメラとレイアウトが
再計算されるだけで、修理の進行状態は失われません。

3Dモデル: 車両・車輪・車体下部品・小物は Kenney「Car Kit」
(https://kenney.nl/assets/car-kit, CC0 1.0 Universal) を使用し、
`scripts/fetch-assets.mjs` で取得したものを `public/assets/kenney/`
に同梱しています（ライセンス文は同ディレクトリの License.txt）。
車体の塗装色は実行時にアトラスの塗装色相域を検出して車ごとに再着色。
整備ロボット・ガレージ・テストコースは手続き生成ジオメトリです。
