# まぜまぜ！へんしんキッチン

4歳児向けのタッチ料理ゲーム。正解や手順ではなく、**指の動かし方で素材が連続的に変身する過程**が主役です。

## 遊び方

`index.html` をブラウザで開くだけ(ビルド・依存なし)。iPhone / iPad の Safari 対応、一本指操作、時間制限・点数・失敗なし。

ローカルサーバーで開く場合:

```
npx serve .
```

## 収録料理と固有の「変身」

| 料理 | 固有の素材変化・操作感・見せ場 |
|---|---|
| パンケーキ | 牛乳の量→生地のゆるさ→広がり方と厚み。混ぜた量と速さ→ダマの残り・気泡→ふくらみ。注いだ場所がそのまま形に。焼き時間が表裏の焼き色に、気泡がはじけてポツポツ穴。フリックで自分でひっくり返す。シロップは指の軌跡どおりにかかる |
| まるパン | こねた量→グルテン→表面のなめらかさと弾力(押すと跳ね返る強さ・へこみの戻る速さが変わる)。あたためた時間→発酵のふくらみ。焼くと窯のび。完成後もつつくと「ぷにぷに」はずむ |
| ふわとろオムレツ | トントン…パカッと卵割り。泡立ての速さ→混ざり方と泡(ふわふわ度)。バターは指でなでて溶かす。**焼きながらかき混ぜる速さでたまごの粒(カード)の大きさが変わる**(ゆっくり=大きなとろとろ、速い=細かいクリーミー)。最後はケチャップでお絵かき |
| サクサククッキー | バターをこすってやわらかく。**麺棒を転がした場所だけ薄くなる「厚さマップ」**。型抜きした場所の厚さがクッキーごとに記録され、**薄いクッキーほど早くこんがり焼ける**(同じ天板で焼きムラが出る)。かじり跡が残る |
| ぷるぷるプリン | **カラメルは白→金→こげ茶へ連続変化、どの色でやめるかは自分しだい**でその色が最後まで残る。混ぜすぎた泡はプリンの「す」になる。蒸し時間+冷やし時間→固まり具合→**ぷるぷる物理の揺れ方が変わる** |
| いちごスムージー | **たたくたびに果肉が半分に割れて小さくなる**(ごろごろ〜なめらかは自分しだい、粒の大きさは完成まで残る)。牛乳の量→色の薄さ。マーブルもよう→ぐるぐるで均一に(果肉も渦に乗って回る)。氷で水滴、ストローで飲める |

## 設計

- 文字は最小(タイトルのみ)。操作はアニメーションする手のピクトグラムで提示
- 各工程は「最低限できたら」右下の矢印が出るが、続けてもよい(こげ茶のクッキーも立派な完成品)
- Canvas 2D によるプロシージャル描画、Web Audio による合成効果音(アセットなし)
- `js/core.js` エンジン(入力・ジェスチャー計測・パーティクル・シーン管理)+ 料理ごとに1ファイル

## 検証

Playwright(Chromium)で全料理・全工程を実ジェスチャー(タップ・ホールド・円描き・こすり・フリック)で通し、
素材パラメータの変化とコンソールエラーゼロを確認済み(縦・横両画面)。
