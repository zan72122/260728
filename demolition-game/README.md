# ばくはつ！かいたいやさん

4歳のお子さま向けの、**3Dビル解体パズルゲーム**です。
かいたいやさんになって、ビルに爆破装置をしかけて、じょうずに「ドッカーン！」と解体しましょう。

- 描画は Three.js による本物の3Dレンダリング（太陽光・やわらかい影・遠景の街なみ・空気遠近）
- 物理は Matter.js の2Dシミュレーション（ブロックの崩壊・がれきの飛散）
- 爆発は閃光＋衝撃波リング＋火花＋コンクリート破片＋もくもくのほこり雲で表現

## あそびかた

1. **▶ あそぶ** をタップして、ステージをえらぶ
2. **せっちフェーズ**: ビルの**すきなブロック**をタップすると、爆破装置（TNT）が貼りつきます
   - 光っているところは「おすすめポイント」。おいた装置は、もう一度タップではずして置き直せます
   - きめられた数をおくと **💥 ばくは かいし！** ボタンが出ます
3. **ばくはフェーズ**: 装置を、すきな順番・タイミングでタップして爆破！
   - 装置は**ブロックにくっついて一緒に動く**ので、くずれた先の「いまの場所」で爆発します
   - 爆風に巻きこまれた装置は**誘爆**、がれきが砕けたときは近くのがれきに乗り移ります
   - **したから順番に**爆破すると、ビルはまっすぐ下にくずれて安全
   - 順番をまちがえると、横にたおれて「おとなり」に当たっちゃうかも
4. ビルがひくくなったらクリア！ ★の数で評価がつきます

### 🔍 みる（カメラ・視点）

- **ピンチズーム**: 2本指を広げる/つまむとズームイン/アウト（PCではマウスホイール）
- **2本指パン**: 2本指を一緒にスライドすると視点がついてきます
- **視点プリセット** `#view-bar`: 🔄しょうめん／◀ひだりから／▶みぎから／🔼うえから、をワンタップで切り替え

### 🛠️ じぶんで つくる（建築モード）

ステージ選択の「じぶんで つくる」から、じぶんだけのビル（マス目 **48×24**、最大 **600マス**）を建てられます。
画面右下の **🎨** ボタンでツールバーをたたむと、画面いっぱいに作品を見わたせます。

- **なぞって描く**: タップした場所だけでなく、指を動かすと**なぞった軌跡に一気に**ブロックが並びます
- **ブラシサイズ**: 1・2×2・4×4・8×8 の4段階。大きなブラシで大型ビルもすぐ完成
- **かたち** `#shape-row`: ■しかく／▲さんかく／●まる の3種類から選べます
- **そざい・いろ** パレット: いろいた5色に加えて、🪨いし／🪵き／⚽ゴム／🧊ガラス の4素材。素材ごとに硬さ・弾み方・くだけやすさが違います（ガラスは弱い衝撃でも砕けます）
- **レイヤー** `#layer-row`: おく／なか／まえ の3層に分けて奥行きのある街なみが作れます
- **かざり** `#decor-row`: 🔺やね／🪟まど／🚪ドア／🚩はた／📡アンテナ を、置いたブロックの上にタップで設置（最大40個）
- **🎲 おまかせ建築**: ワンタップでおしろ・タワー・おうち・ロケット・まちなみのいずれかをオフラインで自動生成
- **🧽 けしゴム**: けしゴムを選んでいるときだけ、なぞったところが消えます（誤削除の防止）
- **自動の柱**: 空中に描くと、下に同じ色の柱が自動で伸びて支えます
- **↩ もどす**: 直前のひと筆をとり消し（もう一度おすと戻せます）

**✅ できた！** をおすと解体タイムへ。爆弾（最大8個）に加えて `#machine-bar` から重機も選べます。
- 💣 ばくだん／🏗️ てっきゅう（振り子でブロックを豪快になぎ倒す）／🚜 ショベル（横から押しくずす）

星評価はなく、なんどでも「もういちど たてる」で同じビルをつくり直せます。

### 🐦 すんでいる子たち

ステージには **とり・ねこ・ふうせん** がのんびり過ごしています。ばくはが始まると、あわてて逃げていきます。

### ひょうか（★1〜3）

- 💨 **ほこりメーター**: 爆発のしすぎ・連続爆破でほこりがもくもく。緑のうちにおさえると★
- 🚧 **がれきの飛散**: オレンジのコーンの内側にがれきをおさめると★
- 🏡 **おとなり**: にこにこしているおとなりの建物に当てると「あちゃー！」→ すぐにもういちど遊べます（きびしいペナルティはありません）

## 動作環境・起動方法

- iPad / iPhone の Safari（縦画面・横画面どちらも対応）、および PC のモダンブラウザ
- ビルド不要。静的サーバーで配信して `index.html` を開くだけです

```bash
cd demolition-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- 効果音とBGMはすべて Web Audio API で合成（外部音源ファイルなし）。iOSの仕様により、音は最初のタップのあとに鳴りはじめます。右上の 🔊 ボタンでミュートできます
- 星の獲得状況は端末の localStorage に保存されます

## 技術構成

```
demolition-game/
  index.html        エントリーポイント
  css/style.css     UIスタイル（縦横レスポンシブ・セーフエリア対応）
  js/
    hooks.js        GameHooks: 拡張機能どうしを疎結合につなぐ軽量イベントバス
                     （levelStart / boomStart / levelEnd / sceneBuilt / frame）
    main.js         起動・シーン管理・入力配線
    game.js         ゲーム進行（自由設置→起爆→評価）、爆弾のブロック追従・誘爆
    build.js        建築モード「じぶんでつくる」（なぞり描き・ブラシ・けしゴム・自動柱・
                     かたち・そざい・3レイヤー、48×24グリッド/最大600マス）
    camera.js       カメラ操作（ピンチズーム・2本指パン・ホイールズーム・視点プリセット）
    decor.js        かざり（やね・まど・ドア・はた・アンテナ）の設置・描画
    procgen.js      🎲 おまかせ建築（おしろ/タワー/おうち/ロケット/まちなみを自動生成）
    machines.js     重機（てっきゅう・ショベル）。建築モードの解体フェーズ専用
    critters.js     住人ギミック（とり・ねこ・ふうせん）。ばくは開始で逃げる
    physics.js      Matter.js ラッパ（建物生成・爆破・崩壊/衝突判定）
    render3d.js     Three.js による3D描画層（ライト・影・カメラ・パーティクル描画）
    levels.js       6ステージのレベルデータ・そざい/ブラシ定義
    ui.js           DOMベースのHUD・画面制御・建築ツールバーの開閉
    effects.js      ほこり・破片・衝撃波・紙吹雪のパーティクルデータ、画面シェイク
    audio.js        Web Audio 合成SFX＋ループBGM
  lib/matter.min.js Matter.js（ベンダリング済み・オフライン動作可）
  lib/three.min.js  Three.js（ベンダリング済み・オフライン動作可）
```

物理は2D（Matter.js）のまま、描画だけを3D化する構成です。物理挙動（崩れ方・難易度チューニング）を保ったまま、
ブロック1つ1つが影を落として転がる立体的な見た目になっています。
カメラ・かざり・おまかせ建築・重機・住人などの拡張機能は `GameHooks` 経由で既存コードに疎結合に差し込まれており、
それぞれ `window.GameCamera` / `window.GameDecor` / `window.GameProcgen` / `window.GameMachines` / `window.GameCritters`
として公開されています。
[Matter.js](https://brm.io/matter-js/) と [three.js](https://threejs.org/)（いずれもMITライセンス）を使用しています。
