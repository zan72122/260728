# ばくはつ！かいたいやさん

4歳のお子さま向けの、**3Dビル解体パズルゲーム**です。
かいたいやさんになって、ビルに爆破装置をしかけて、じょうずに「ドッカーン！」と解体しましょう。

- 描画は Three.js による本物の3Dレンダリング（太陽光・やわらかい影・遠景の街なみ・空気遠近）
- 物理は Matter.js の2Dシミュレーション（ブロックの崩壊・がれきの飛散）
- 爆発は閃光＋衝撃波リング＋火花＋コンクリート破片＋もくもくのほこり雲で表現

## あそびかた

1. **▶ あそぶ** をタップして、ステージをえらぶ
2. **せっちフェーズ**: ビルの上で光っているところをタップすると、爆破装置（TNT）がおかれます
3. **ばくはフェーズ**: おいた装置を、すきな順番・タイミングでタップして爆破！
   - **したから順番に**爆破すると、ビルはまっすぐ下にくずれて安全
   - 順番をまちがえると、横にたおれて「おとなり」に当たっちゃうかも
4. ビルがひくくなったらクリア！ ★の数で評価がつきます

### ひょうか（★1〜3）

- 💨 **ほこりメーター**: 爆発のしすぎ・連続爆破でほこりがもくもく。緑のうちにおさえると★
- 🚧 **がれきの飛散**: オレンジのコーンの内側にがれきをおさめると★
- 🏡 **おとなり**: にこにこしているおとなりの建物に当てると「あちゃー！」→ すぐにもういちど遊べます（きびしいペナルティはありません）

## 動作環境・起動方法

- iPad / iPhone の Safari（縦画面・横画面どちらも対応）、および PC のモダンブラウザ
- ビルド不要。静的サーバーで配信して `index.html` を開くだけです

```bash
cd demolition-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- 効果音とBGMはすべて Web Audio API で合成（外部音源ファイルなし）。iOSの仕様により、音は最初のタップのあとに鳴りはじめます。右上の 🔊 ボタンでミュートできます
- 星の獲得状況は端末の localStorage に保存されます

## 技術構成

```
demolition-game/
  index.html        エントリーポイント
  css/style.css     UIスタイル（縦横レスポンシブ・セーフエリア対応）
  js/
    main.js         起動・シーン管理・入力配線
    game.js         ゲーム進行（設置→起爆→評価）
    physics.js      Matter.js ラッパ（建物生成・爆破・崩壊/衝突判定）
    render3d.js     Three.js による3D描画層（ライト・影・カメラ・パーティクル描画）
    levels.js       6ステージのレベルデータ
    ui.js           DOMベースのHUD・画面制御
    effects.js      ほこり・破片・衝撃波・紙吹雪のパーティクルデータ、画面シェイク
    audio.js        Web Audio 合成SFX＋ループBGM
  lib/matter.min.js Matter.js（ベンダリング済み・オフライン動作可）
  lib/three.min.js  Three.js（ベンダリング済み・オフライン動作可）
```

物理は2D（Matter.js）のまま、描画だけを3D化する構成です。物理挙動（崩れ方・難易度チューニング）を保ったまま、
ブロック1つ1つが影を落として転がる立体的な見た目になっています。
[Matter.js](https://brm.io/matter-js/) と [three.js](https://threejs.org/)（いずれもMITライセンス）を使用しています。
