# 🥞 パンケーキタワーすべり解体

ふわふわに積み上がったパンケーキの塔を、シロップやバターで「ずるっ」「どさっ」とくずして、
お皿にサーブしてあげる 3D おもちゃ箱ゲームです。
4歳のお子さま向けに、**文字なし・タップとドラッグと長押しだけ** で遊べるように作られています。

## あそびかた

1. `index.html` をブラウザで開くだけで遊べます（インストール・通信不要）。
   iPad / iPhone の Safari、縦画面・横画面のどちらでも遊べます。
2. 最初の画面をタップするとパンケーキが焼き上がって、塔が積み上がります。
3. 画面下のまるいボタンをタップすると、トッピングのお花パレットが開きます。
4. すきな素材を選んで、塔をさわってみてください。
   塔がかたむいて、すべって、お皿にくずれます。**おなじ崩れ方は二度とありません。**

| 素材 | さわりかた | 塔へのえいきょう |
|------|-----------|------------------|
| 🍯 シロップ | なぞって そそぐ | かけた層が **つるつる** になって、かけた側へ ずるずる すべりだす |
| 🍫 チョコ | なぞって そそぐ | とろり→ **カチッと固まって層どうしがくっつき**、かたまりごと どさっと落ちる |
| 🧈 バター | タップで置く | じんわり溶けて、その層の下が **超つるつる** に |
| 🍦 クリーム | **長押し** で大きくなる | 置いた側が **重く** なって、塔がぐぐっとかたむく（ねばねばなので滑らず倒れる） |
| 🍓 いちご | タップで置く | 片側だけ重くなってかたむく。塔がゆれると **ころころ転がり落ちる** |
| 👆 ゆび | タップでつんつん | ぷにっと押して、ちょっとだけずらす |

- パンケーキが **まわりの小さなお皿に着地すると ⭐（レインボーは⭐×3）**。
  テーブルに落ちても ♡ が出ます。失敗はありません。
- 塔をぜんぶくずすと紙吹雪のお祝い。まんなかの大きなボタンで **つぎのもっと高い塔** へ。
- ⭐が貯まると、せかいに 🌈（15個）→ 🎈（40個）→ 🏰（80個）の飾りがふえていきます
  （ブラウザに自動保存されます）。
- 右上の `🥞↻` でいつでも焼き直し、左上の 🔔 で音の入り切りができます。

## しくみ（保護者・開発者向け）

物理は **4状態のハイブリッド構成** で、状態の切り替わりでも姿勢と速度が
完全に連続になるよう作られています（カクつきなし）。

1. **stack（塔）— 自作ソルバー**
   「どの素材をどこに置いたか」が崩れ方に直結するよう、層ごとの
   摩擦・重心・接着を直接あつかいます。
   - 各層は下の層と **粘性結合** されていて、下が動くと少し遅れて追従します
     → 塔が板のように平行移動せず、**S字にしなって** ずれます。
   - 滑り出す直前は **マイクロスリップ**（数ミリ滑ってピタッと止まる）が
     「ぎし…ぎし…」と起きて、崩壊の予兆が読めます。
   - 動いている層は **一定減速度の動摩擦** で滑り続けるので、
     つんつんの勢いやシロップのつるつる度が滑走距離にそのまま現れます。
   - 片側に重い物を置くと層が **たわんで傾き**（loadTilt）、上の層ほど
     大きく傾いて塔全体がしなります。
2. **tipping（倒れ込み）**
   支えを失った層は即落下せず、下の層の **ふちを支点にした倒立振り子** として
   0.3〜1.5秒かけて「じわ…っ」と倒れ込みます。
3. **free（落下）— cannon-es 剛体エンジン**
   倒れ込みの姿勢・角速度をそのまま引き継いで放り出されます。
   パンケーキ同士・皿・床・**立っている塔** とも本当に衝突し、
   チョコで接着された層は複合剛体として塊のまま落ちます。
4. **landed（着地）**
   眠った剛体は **その姿勢のまま** 静的化します（整列スナップなし）。
   斜めに立て掛かったり重なったりした自然な山になり、
   あとから落ちてくるパンケーキはその山にぶつかります。

見た目の柔らかさは頂点シェーダーで表現しています:
ふちの支えがない側が **ふにゃっと垂れ（ドレープ）**、衝撃で **ぷるんと波打ち
（ジグル）** ます。

- サウンドはすべて WebAudio でリアルタイム生成（音声ファイルなし）。
  BGM はペンタトニックのオルゴール風自動作曲です。
- 3D 描画は Three.js r147、剛体は cannon-es 0.20.0
  （どちらも `vendor/` に同梱、オフライン動作）。

## ファイル構成

```
pancake-tower/
├── index.html        エントリーポイント（これを開く）
├── README.md
├── css/style.css     全画面UI・パレット・演出のスタイル
├── vendor/           Three.js r147 / cannon-es 0.20.0（ともにMIT）同梱
└── js/
    ├── utils.js      定数・乱数・キャンバステクスチャ工房（顔・空・生地）
    ├── audio.js      WebAudio効果音とオルゴールBGM
    ├── effects.js    きらきら・紙吹雪・しずく・星の飛翔
    ├── world.js      シーン・ライト・お皿・雲・ごほうびの飾り・カメラ
    ├── pancake.js    パンケーキ本体（顔・ふわもち頂点シェーダー）と塔の生成
    ├── physics.js    ハイブリッド物理（せん断ソルバー+tipping+cannon-es）
    ├── toppings.js   6種の素材の効果と見た目
    ├── ui.js         お花パレットなど最小UI
    └── game.js       ラウンド進行・入力・メインループ
```
