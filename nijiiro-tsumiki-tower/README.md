# 🌈 にじいろつみきタワー

4歳の女の子のための、やさしい 3D「積み木タワーくずし」ゲームです。
高く積まれた虹色の積み木タワーに、**まほうのシール**を貼って、
**ぽんスイッチ**を押すと……タワーが毎回すこし違うかたちで崩れます。

文字が読めなくても遊べます。失敗はありません。
崩れなくても、崩れすぎても、ぜんぶ「たのしい結果」です。

---

## あそびかた

1. **シールをえらぶ** … 画面下のパレットから好きなシールをタップ
2. **タワーにはる** … 積み木をタップするとシールがペタッ（もう一度タップではがせる）
3. **ぽん！** … ピンクの大きなボタンを押すと、貼った順番にシールが発動
4. **ながめる** … タワーがゆらゆら、ドキドキ、がらがらっ……
5. **おそうじぽん** … 結果のあとは、残った積み木をタップすると音階つきで消せる

### まほうのシール（3つの「ほうこう」の魔法）

| シール | なまえ | おこること | ほうこう |
|--------|--------|-----------|----------|
| ⭐ ほし | ぽんっ | 積み木がキラキラと消えて、支えがなくなる | ⬇ した |
| 💗 はーと | ふわ〜 | 積み木が風船になって、ゆっくり浮かんでいく | ⬆ うえ |
| 🌈 にじ | つるん | 積み木がつるつるになって、横にすべりだす | ➡ よこ |

「どこを弱くすると、どう崩れるか」を予想して遊びます。
物理シミュレーションなので、結果は毎回すこしだけ違います。

### そうさ

- **タップ** … シールを貼る／はがす、ボタンを押す、おそうじぽん
- **ドラッグ** … カメラをぐるっと回す
- **ピンチ** … ズームイン／アウト

### けっか

- 崩れた「高さの合計」が、左のにじメーターにたまります
- ⭐1〜3個で評価（0個でも罰はなし。うさぎさんはいつもよろこびます）
- **↺** … 同じタワーでもう一回（予想の答え合わせができる、大事なボタン）
- **▶** … つぎの新しいタワーへ

| 🎂 | さんだんケーキ | 柱とお皿の3段。柱を消すとお皿ごとすべる |
| 🏰 | おしろ | 四隅の塔と丸太組みの橋、中央の高い塔 |

## 動かしかた

ES Modules を使っているため、**HTTPで配信して開く**必要があります
（`index.html` のダブルクリックでは動きません）。

### かんたん（ローカル）

```bash
cd nijiiro-tsumiki-tower
npx serve .        # または python3 -m http.server 8000
```

表示された URL を iPad / iPhone の Safari で開きます。

### おすすめ（GitHub Pages）

リポジトリの Settings → Pages でこのブランチを公開すると、
`https://<user>.github.io/<repo>/nijiiro-tsumiki-tower/` で遊べます。
Safari の共有メニューから **「ホーム画面に追加」** すると、
全画面のアプリのように遊べます（アイコンつき）。

- 対応: iOS/iPadOS Safari(14+)、Chrome、Edge。縦画面・横画面どちらも対応
- 外部通信なし・広告なし・課金なし。進行状況は端末の localStorage に保存

```
│   ├── main.js         # ゲーム本体（3D描画・物理・入力・演出・進行）
│   ├── towers.js       # タワー設計図の生成（純粋データ、Node でも動く）

│   └── cannon-es.js          # cannon-es 0.20（物理エンジン）

```

## 検証（開発者向け）

```bash
node test/stability.mjs
```

全ステージについて次の2点を、実際の物理シミュレーションで検証します。

1. **勝手に崩れない** … 全積み木を物理的に起こして10秒放置してもタワーが自立する
2. **ちゃんと崩れる** … 土台近くの積み木を⭐で2個消すと、確実に崩れが発生する

ブラウザのコンソールでは `window.NIJI` からゲーム状態（state / score など）を
のぞけます（E2E テスト用のフック）。

## 設計メモ

- **因果の見えやすさ**: 3つのシール＝「下・上・横」の3方向。発動は貼った順に
  0.78秒間隔で1つずつ。目と耳で「どれが何をしたか」が追えるようにしてある
- **安定性の作り**: 積み木はぴったりの格子座標に置いて即スリープさせるので、
  触らない限り絶対に崩れない。ぽんスイッチで全員起床 → シール発動、の順
- **毎回ちがう結果**: タワー生成の微小な位置ゆらぎ＋物理のカオス性＋
  シール発動時のランダムな微小インパルス。同じシード（↺）でも少し変わる
- **罰なし設計**: スコアは「崩れた高さの割合」の加点のみ。0点でも
  キャラクターは祝ってくれて、おそうじぽんのご褒美タイムがある
- **チューニング**: 物理定数は `js/towers.js` の `PHYS`、
  シールの強さは `js/main.js` の `activateSticker()` にまとまっている
