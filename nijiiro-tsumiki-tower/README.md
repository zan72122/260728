# 🌈 にじいろつみきタワー

4歳の女の子のための、3D「積み木タワー解体」ゲームです。
高く積まれた虹色の積み木タワーに **こわし装置** をとりつけて、
**ぽんスイッチ**を押すと……タワーが毎回すこし違うかたちで崩れます。

文字が読めなくても遊べます。失敗はありません。
崩れなくても、崩れすぎても、ぜんぶ「たのしい結果」です。

---

## あそびかた

1. **そうちをえらぶ** … 画面下のパレットから好きな装置をタップ
2. **タワーにつける** … 積み木をタップすると装置がカチッ（もう一度タップではずせる）
3. **ぽん！** … ピンクの大きなボタンを押すと、つけた順番に装置が発動
4. **ながめる** … ドキドキ……シューッ……ドカーン！がらがらっ……
5. **おそうじぽん** … 結果のあとは、残った積み木をタップすると音階つきで消せる

### こわし装置（現実で知っている因果を そのまま使う）

| 装置 | おこること | とくい |
|------|-----------|--------|
| 💣 ばくだん | 導火線がシューッと燃えて、ドカーン！ 近くの積み木は粉々、まわりは吹き飛ぶ | 広いはんいを一気に |
| 💨 せんぷうき | 積み木のそばに浮かんで、ビュオーッと3秒間送風。じわじわ押し倒す | 横からじわじわ |
| 🔨 ハンマー | 的(まと)マークをつけた積み木を、大きなハンマーがゴツン！と一撃 | ねらった一点 |

爆弾=広範囲、扇風機=持続する横押し、ハンマー=一点強打。
「どこに何を置くと、どう崩れるか」を予想して遊びます。
物理シミュレーションなので、結果は毎回すこしだけ違います。

### そうさ

- **タップ** … 装置をつける／はずす、ボタンを押す、おそうじぽん
- **ドラッグ** … カメラをぐるっと回す
- **ピンチ** … ズームイン／アウト

### けっか

- 崩れた「高さの合計」が、左のにじメーターにたまります
- ⭐1〜3個で評価（0個でも罰はなし。うさぎさんはいつもよろこびます）
- **↺** … 同じタワーでもう一回（予想の答え合わせができる、大事なボタン）
- **▶** … つぎの新しいタワーへ

## 動かしかた

ES Modules を使っているため、**HTTPで配信して開く**必要があります
（`index.html` のダブルクリックでは動きません）。

### かんたん（ローカル）

```bash
cd nijiiro-tsumiki-tower
npx serve .        # または python3 -m http.server 8000
```

表示された URL を iPad / iPhone の Safari で開きます。

### おすすめ（GitHub Pages）

リポジトリの Settings → Pages でこのブランチを公開すると、
`https://<user>.github.io/<repo>/nijiiro-tsumiki-tower/` で遊べます。
Safari の共有メニューから **「ホーム画面に追加」** すると、
全画面のアプリのように遊べます（アイコンつき）。

- 対応: iOS/iPadOS Safari(14+)、Chrome、Edge。縦画面・横画面どちらも対応
- 外部通信なし・広告なし・課金なし。進行状況は端末の localStorage に保存

## 検証（開発者向け）

```bash
node test/stability.mjs
```

全ステージについて次の2点を、実際の物理シミュレーションで検証します。

1. **勝手に崩れない** … 全積み木を物理的に起こして10秒放置してもタワーが自立する
2. **ちゃんと崩せる** … 💣を低層の候補地点（最大6か所）で爆発させると、
   少なくともどこか1か所で しっかりした崩れ（高さの15%以上）が起きる

ブラウザのコンソールでは `window.NIJI` からゲーム状態（state / score など）を
のぞけます（E2E テスト用のフック）。

## 設計メモ

- **因果の見えやすさ**: 装置は「爆発・風・打撃」という現実で体感済みの因果を
  そのまま使う。発動はつけた順に1.15秒間隔で1つずつ、導火線→爆発のような
  「ため」を挟み、目と耳で「どれが何をしたか」が追えるようにしてある
- **安定性の作り**: 積み木はぴったりの格子座標に置いて即スリープさせるので、
  触らない限り絶対に崩れない。ぽんスイッチで全員起床 → 装置発動、の順
- **爆発の物理**: 密着した積み木の山は接触と摩擦がインパルスを吸収してしまう。
  そこで爆心近く（breakRadius）は粉砕して穴を開け、強い上向き成分で
  積み木を宙に浮かせて摩擦から解放している（`towers.js` の `BOMB`）
- **毎回ちがう結果**: タワー生成の微小な位置ゆらぎ＋物理のカオス性＋
  発動時のランダムな微小さじ加減。同じシード（↺）でも少し変わる
- **罰なし設計**: スコアは「崩れた高さの割合」の加点のみ。0点でも
  キャラクターは祝ってくれて、おそうじぽんのご褒美タイムがある
- **チューニング**: 物理定数と爆弾の威力は `js/towers.js` の `PHYS` / `BOMB`、
  風とハンマーの強さは `js/main.js` の `applyWind()` / `hammerImpact()` にある
