# スポンジまてんろう 🧽🌈

4さいのお子さま向けの、さわって観察する 3D スポンジトイです。
高く積まれたカラフルなスポンジの塔に **水をかけたり、乾かしたり、風を送ったり、クッションを置いたり** して、
塔がゆっくり傾き、へこみ、思いがけない形でやさしく崩れていく様子を楽しみます。

- 文字が読めなくても遊べます（UIは絵と色だけ）
- 失敗はありません。崩れたら「みんなおやすみ😴」＝ごほうびイベントです
- iPad / iPhone の縦画面・横画面どちらでも遊べます
- 完全オフライン動作（外部CDN・音源ファイル不使用）

## 起動方法

`index.html` をブラウザで開くだけで動きます（`file://` 直開きでもOK）。

きれいに動かすおすすめ手順：

```bash
cd sponge-skyscraper
python3 -m http.server 8000
# iPad/iPhone の Safari で http://<PCのIPアドレス>:8000 を開く
```

Safari の共有メニューから「ホーム画面に追加」すると、全画面のアプリのように遊べます。

## あそびかた（おうちの方へ）

| ボタン | どうぐ | できること |
|---|---|---|
| 💧 | みず | **タップ＝みずふうせん**がポーンと飛んで、着弾でバシャッと広いはんいが一気に濡れてぷにぷに波が伝わります。**長押し＝シャワー**で、構造の大きさに応じた広いブラシ（小スポンジなら一度に数十個）をたっぷり濡らせます。濡れた水は**下へ流れて濡れ筋**になり、張り出しからポタポタ滴ります |
| ☀️ | おひさま | 乾かします（みずと同じ広さ）。湯気が出て、へこんだスポンジが**ぷるんと立ち直ります** |
| 🌬️ | かぜ | 画面をドラッグした方向に風が吹き、塔がゆらゆら揺れます。乾いた軽いスポンジほどよく揺れます |
| 🌧️ | あめくも | **⭐を1個とると解禁されるごほうびツール**。指の下にふわふわの雨雲が現れ、雲の下がぜんぶ雨で濡れます。**長押しでどしゃぶり**（雲が大きく灰色になり、雨足が強まります） |
| 🛏️ | クッション | 地面をタップするとふわふわクッションが生えます。倒れそうな側に置くと**塔を支え**、落ちてきたスポンジは**ぼよ〜んと跳ねます** |
| 🔄 | もういちど | スポンジたちが飛んで帰ってきて、塔が組み直されます（顔ぶれと色が毎回少し変わります） |
| 🏠 | とうえらび | 塔の種類を選び直します |

- **1本指ドラッグ**（塔から離れた場所）: カメラ回転
- **2本指ドラッグ / ピンチ**: カメラ回転・ズーム
- しばらく触らないと、カメラがゆっくり回る「ながめモード」になります

### ごほうび

塔がぜんぶ崩れて、スポンジが**みんな地面ですやすや眠る**と、紙吹雪と一緒に ⭐ がもらえます。
⭐ が7つたまると 🌈 が完成して、スポンジたちがキラキラ光るようになります（進捗は自動保存されます）。

## 端末負荷への配慮（自動チューニング）

- 起動時にCPUマイクロベンチマークを実行し、**high / mid / low** の品質ティアを自動選択します
  （上限はそれぞれ約3,000 / 1,700 / 850個。ボクセルアートの解像度ごと変わるので、形は保たれたまま粒の細かさが変わります）
- 実行中も平均fpsを監視し、かくつく場合は粒子エフェクトと影を自動で減量します
- URLに `?tier=high` `?tier=mid` `?tier=low` を付けると手動で固定できます

## しくみ（技術メモ）

- **レンダリング**: Three.js r147（`lib/three.min.js` に同梱）。角丸ブロックは ExtrudeGeometry のベベルで生成。
  「いっぱいスポンジ」は **InstancedMesh 1つ**（インスタンス色つき）で数千個を1ドローコール描画
- **物理**: 専用の簡易ソフトボディ。各ブロックが `wet`（濡れ＝重さ・柔らかさ）、`squash`（つぶれ、ばね）、`shear`（横ずれ、ばね）を持ち、
  - 濡れ→剛性低下＋質量増→上載荷重でつぶれ、濡れた側へスランプ
  - 塔全体の重心オフセットが不感帯を超えると正帰還でゆっくり倒れ始める（＝観察できる崩壊）
  - 関節ごとに「上部の重心が支持面を出たか」を判定して上部を切り離し、スローモーの自由落下＋ぷにぷに着地
  - 個体ごとの乱数（`wobble`）で毎回崩れ方が変わる
- **ボクセル物理**: 構造を縦の「柱」に分解し、柱単位で shear/squash ばねを計算（O(N)）
  - 隣接柱とのしなり拡散で壁が一体になって揺れ、ずぶ濡れの背高柱は圧縮で座屈
  - 接地していない柱（アーチ・屋根）は下・横のささえを失うと少し遅れて落ち、連鎖崩壊になる
  - 落下ボクセルは空間ハッシュでご近所だけ衝突判定。眠った子は静的化して負荷ゼロ
  - 形は数式ベース（ハート陰関数・星型多角形・楕円合成など）で生成するため、解像度が変わっても同じ形
- **サウンド**: 全て WebAudio でリアルタイム合成（`js/audio.js`）。じょうろ・風・みしみし・ぷに・ぼよん・チャイムなど。初回タッチでアンロック（iOS対応）
- **顔・地面・空・粒子**: 全て Canvas で動的生成（画像ファイルなし）
- **水の相互作用**: ブラシは構造サイズ連動の球形（`waterBrushR`）。タップは水風船（放物線→着弾で広域ソーク＋外へ伝わる膨張波）、
  長押しはシャワー。濡れは柱内を下方へ流れて濡れ筋を作り、最下部から滴って水たまりになる。
  あめくもは⭐1個で解禁され、雲の下の各柱の上面に雨を降らせる（長押しでどしゃぶり）
- **保存**: ⭐ の数（現在・通算）のみ `localStorage`
- **テスト用フック**: `window.__SPONGE__`（`state()` / `cols()` / `wetSum()` / `wetAll(n)` / `balloons()` / `tier`）で状態取得・検証が可能（自動テスト用、ゲームに影響なし）
