# 🌈 にじいろぽたぽたラボ — Rainbow Drip String Lab

4歳の子どものための、さわると世界が変わる物理おもちゃゲームです。
ピンを置き、たわむ紐を張り、色つきのしずくを降らせて、
しずくが紐を伝い、集まり、落ち、カップを満たし、花を咲かせる——
その連鎖反応を自由に実験して遊びます。

失敗もタイマーもスコアもありません。文字が読めなくても遊べます。

## 遊びかた

| そうさ | できること |
| --- | --- |
| ☁️ 雲をタップ / 長押し | しずくが降る(長押しで雨) |
| ☁️ 雲を左右にドラッグ | 降らせる場所を動かす |
| 🎨 上の色ボタン | しずくの色をえらぶ(にじボタンもあるよ) |
| 📍 ピンツールで板をタップ | ピンを置く |
| 📍 ピンをドラッグ | ピンのお引っ越し(紐もいっしょに動く) |
| 🧶 ひもツールでピンからピンへドラッグ | たわむ紐を張る(タップ→タップでもOK) |
| 🧽 けしごむでタップ | ピンや紐を消す |
| ↩️ もどすボタン | ひとつ前にもどす |
| 🫧 おそうじボタン | 液体とシミだけ片づける(紐は残る) |
| 🔄 リセットボタン | 最初からやりなおす |

## しかけ

- **紐**: 懸垂線(カテナリー)風にたわみ、しずくが乗ると少し沈む
- **しずく**: 紐の斜面を滑り、低い所に集まり、合体して育ち、重くなるとぽたり
- **混色**: 絵の具(RYB)モデル。赤+黄=橙、黄+青=緑、青+赤=紫
- **カップ**: たまって、あふれて、小川になる
- **花**: お水の色に染まって咲き、満開になるとキラキラ
- **スポンジ**: 吸って、色が染みて、飽和すると底からぽたぽた
- **紙**: 水彩のにじみがじわっと広がる
- **水たまり**: 床で広がり、混ざり、大きくなるとツヤツヤ光る

## 起動方法

ビルド不要・依存なし(素の ES Modules)。ローカルサーバーで開くだけです。

```bash
cd rainbow-drip-string-lab
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

タブレットでの全画面プレイがおすすめです。効果音はすべて WebAudio で
その場で合成しているため、音声ファイルもありません。

## 設計メモ

- しずくは紐上では「接線方向の重力成分」で加速する簡易モデル
- しずくの上限(150)を超えると古く小さいものから静かに消える
- シミはオフスクリーンキャンバスに蓄積するため、増えても描画コスト一定
- すべてのタッチターゲットは 48px 以上
