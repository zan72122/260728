# いろのたね ラボ 🌈🫧

4歳児向けの「色の種を置くと、泡やゼリーの庭が自然に分かれていく実験装置」型ゲームです。
浅い水たまりに色の種を置くと、その周りから色がじわっと広がり、隣の色とぶつかった所に
キラキラ光る境目ができます。種を指で動かすと、境目もぬるっとついてきます。

数学的な裏テーマはボロノイ図（最近傍領域・泡の分割）ですが、画面に数学は一切出てきません。
正解も不正解もなく、色の陣地・泡のステンドグラスを自由に作る遊びです。

## あそびかた（文字が読めなくてもOK）

すべて直接操作と大きなアイコンだけで遊べます。

| そうさ | なにがおこる |
| --- | --- |
| 水たまりを ちょん | 選んでいる色の種が生まれて、色がじわっと広がる |
| 種を ドラッグ | 種がうごいて、境目も ぬるっとついてくる |
| 種を ちょん（別の色を選んでいる時） | 種がその色に変身する |
| 🌱 ボタン | 種をおく・うごかす モード |
| 🚿 ボタン → 水たまりを ちょん | 水がかかって、近くの種がぐんぐん育つ |
| 🫧 ボタン → 水たまりを ちょん | 泡がぶくぶく出て、庭ぜんたいが ぷるぷるゆれる |
| いろまる ボタン | つぎに置く種の色をえらぶ |
| 🧹 ボタン | ぜんぶの領域がしゅるしゅる縮んで、まっさらに戻る |
| 🔊 / 🔇（右上） | 音のオン・オフ |

## 下流の変化（領域が育つと…）

- 🔴 赤の領域 → お花が咲く
- 🟠 橙の領域 → ちょうちょが ひらひら
- 🟡 黄の領域 → 泡が ぶくぶく わく
- 🟢 緑の領域 → 芽が すくすく 出る
- 🔵 青の領域 → 池になって 波紋と小さな魚
- 🟣 紫の領域 → 星が またたく
- 領域同士が初めてぶつかると、境目に光の線とキラキラ、やさしいチャイムが鳴る

領域の色が変わったり縮んだりすると、そこに居た飾りは そっと消えていきます。

## 動かしかた

ビルド不要の静的サイトです。ES Modules を使うためローカルサーバーから開いてください。

```bash
cd color-seed-lab
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

タブレットのタッチ操作・マウスのどちらでも遊べます。

## しくみ（大人向けメモ）

- 領域は「加法的重み付きボロノイ図」です。各セルについて
  `score = 距離(セル, 種) − 種の半径 + ゆらぎノイズ` を計算し、score が最小の種が
  そのセルの持ち主、`score < 0` のセルだけ色が塗られます。種の半径が時間とともに
  育つので、領域が連続的に「じわっ」と広がり、隣とぶつかった所が境目になります。
- ゆらぎノイズは種ごとに違う場所を参照し、さらに時間の正弦波で振幅を揺らすので、
  境目は硬い直線ではなく、にじんで ぷるぷる揺れるゼリーの縁になります。
- 計算は低解像度グリッド（1セル約6px）で行い、拡大描画のスムージングで
  やわらかい見た目にしています。

## ファイル構成

```
color-seed-lab/
├── index.html        エントリ HTML
├── README.md         このファイル
├── css/
│   └── style.css     大きなボタンのツールバーなど UI スタイル
└── js/
    ├── config.js     色・成長・演出のパラメータ定義
    ├── noise.js      バリューノイズ（にじみ・ゆらぎ用）
    ├── field.js      成長ボロノイ場の計算と低解像度描画（コア）
    ├── seeds.js      種の管理（置く・育つ・動かす・水やり）
    ├── particles.js  キラキラ・水滴・泡・波紋パーティクル
    ├── decor.js      領域に生まれる花・蝶・魚などの下流演出
    ├── sound.js      WebAudio のやさしい効果音シンセ
    ├── ui.js         文字なし大アイコンのツールバー
    └── main.js       入力処理とメインループ
```
