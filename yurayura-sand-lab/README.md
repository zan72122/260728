# ゆらゆら すなもよう ラボ

4歳児向けの、揺れと砂で模様を作る実験装置型ゲームです。
画面上部のフックから吊られたカップを引っぱって離すと、カップが振り子のように揺れながら色砂を落とし、床の「かみ」に美しい曲線や輪の模様が残ります。

## あそびかた

| そうさ | なにがおきる |
| --- | --- |
| カップを ゆびで ひっぱって ぱっと はなす | カップが ゆらゆら ゆれて、すなの もようが できる |
| かみの どこかを とんとん たたく | カップを そっと おして、ゆれが かわる |
| 左右に スワイプ | すなの いろが かわる(メニューを とじた とき) |
| かみ右下の 🎨 ボタン | メニューを ひらく/とじる(いろ・アクション・バッジ・おと) |
| 🥄 すなを いれる / 🌫️ きり / 📄 かみを かえる | メニューを ひらいた とき に えらべる |

すなは「いちご・そーだ・れもん・めろん・ぶどう・にじ・ほしくず・こなゆき」の8しゅるい。
「よるのそら」のかみに「ほしくず」や「こなゆき」をまくと、よぞらに ひかる もようになります。

画面は**全画面**です。フック・カップ・かみが ブラウザいっぱいに ひろがり、操作は 🎨 ボタンから ひらく メニューに まとまっています。
タブレット(縦・横)・スマホに対応しています。

## 起動方法

ビルド不要の静的サイトです。このフォルダで簡易サーバーを立ててください
(ES モジュールを使っているため、`file://` 直接オープンではなくサーバー経由を推奨します)。

```bash
cd yurayura-sand-lab
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

タッチ操作対応。タブレットの縦持ちがいちばん遊びやすいレイアウトです。
音は Web Audio API でその場で合成しており、外部アセットはありません(右上 🔊 で消音できます)。

## 大人向け:裏側のしくみ

子どもには見せませんが、模様の正体は次の数学・物理です。

- **減衰振動** — カップは `x'' = -ω²x - 2λx'` に従う2次元の減衰振動子。揺れが小さくなるほど砂が濃く溜まり、模様が中心へ収束します。
- **リサージュ曲線** — 離すたびに x/y の角振動数比をランダムに選びます(ほぼ 1:1、わずかな差、2:3 / 1:2 / 3:4 など)。比によってリング・花・網目と模様の系統が変わります。
- **ハーモノグラフ** — 速度に直交する弱い力(歳差項)を加えることで、実物のハーモノグラフのように楕円がゆっくり回転しながら描かれます。
- **流量と線の濃淡** — 砂は時間あたり一定量で落ちるため、カップが速いところは薄く細く、遅いところ(折り返しや終わり)は濃く溜まります。これも実物の砂振り子と同じ現象です。

同じように引っぱっても、振動数比・減衰率・歳差・砂の流量が毎回わずかにランダム化されるので、二度と同じ模様にはなりません。

## ファイル構成

```
yurayura-sand-lab/
├── index.html        画面の骨組み
├── css/
│   └── style.css     見た目(パステル・大きなボタン)
└── js/
    ├── main.js       入力・ゲームループ・モジュールの糊付け
    ├── config.js     定数・すな/かみ/バッジのカタログ
    ├── pendulum.js   振り子の物理(減衰・周波数比・歳差)
    ├── sand.js       砂の放出・落下・堆積・にじみ・霧
    ├── render.js     カップ・ひも・かみ・影の描画
    ├── audio.js      Web Audio による効果音の合成
    ├── ui.js         パレット・ボタン・バッジ・ポップアップ
    └── utils.js      汎用ヘルパー
```
