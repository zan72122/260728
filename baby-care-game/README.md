# あかちゃん おせわランド 👶🌈

4歳のお子さま向けの、3D赤ちゃんお世話ゲームです。
ピンクのファンタジーなお部屋で、赤ちゃんのおむつを替えてニコニコにしてあげましょう。

## あそびかた

1. 「タップして はじめる」をタップ
2. 画面下の **「おむつ こうかん」ボタン** をタップ
3. あとは画面の 👆 マークとメッセージのとおりに！
   - **おむつを タップ** → ぽーんとおむつポットへ
   - **ゆびで ふきふき**（3回スワイプ）→ ぴかぴかに
   - **あたらしい おむつを タップ** → できあがり！⭐がもらえます
4. 赤ちゃんを直接タップすると、くすぐったくて笑います 💗

- ごきげんゲージが減ってぐずりだしたら、おむつ替えのサインです（失敗やゲームオーバーはありません）
- 1本指ドラッグでカメラをぐるぐる、2本指ピンチでズームできます
- ⭐の数とミュート設定は自動で保存されます

## 動かしかた

ビルドは不要です。フォルダごと静的Webサーバーに置くだけで動きます。

```bash
cd baby-care-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages などにそのまま配置してもOKです
（ES Modules を使っているため、`file://` 直開きではなくWebサーバー経由で開いてください）。

- 対象デバイス: iPad / iPhone（Safari）、縦画面・横画面どちらも対応
- 音はすべて Web Audio でリアルタイム合成（音声ファイルなし）

## フォルダ構成

```
baby-care-game/
├── index.html      … エントリーポイント
├── css/style.css   … UIスタイル（HUD・ボタン・メッセージ）
├── js/
│   ├── main.js     … 起動・カメラ・入力・メインループ
│   ├── world.js    … お部屋・虹・雲・家具などの3Dワールド
│   ├── baby.js     … 赤ちゃんの3Dモデルとアニメーション
│   ├── game.js     … おむつ交換の進行とごきげんゲージ
│   ├── particles.js… ハート・キラキラなどの演出
│   ├── audio.js    … BGM・効果音（Web Audio合成）
│   ├── ui.js       … 画面上のUI操作
│   └── tween.js    … アニメーション補間ヘルパー
└── lib/            … Three.js 本体（同梱・CDN不要）
```

## 技術メモ

- Three.js r160（`lib/` に同梱、ネット接続なしでも動作）
- 壁は部屋の内側だけを描画する片面ポリゴンなので、カメラを外に回すと自動で壁が消えて中が見えます（ドールハウス方式）
- 進行状況（⭐）は `localStorage` に保存
