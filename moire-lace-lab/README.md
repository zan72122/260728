# レースのまほうラボ

4歳児向けの、線と模様を重ねて遊ぶ実験装置型ゲームです。
「透明なレース布を重ねると、大きな波模様が現れるラボ」をテーマに、
細かい縞や点の入った透明シートを指でずらしたり回したりすると、
画面いっぱいに大きな波・渦・花のような **モアレ模様** がぬるっと現れます。

正解も不正解もありません。きれいな重なりを見つけることが遊びの目的です。

## あそびかた

文字が読めなくても遊べるよう、操作は指での直接操作と大きなアイコンだけです。

### 指での操作

| 操作 | できること |
| --- | --- |
| 1本指でドラッグ | 上のシートをずらす (模様が大きく流れる) |
| 2本指でひねる | シートを回す (渦や波がまわる) |
| 2本指でつまむ | 少し拡大縮小 (模様が開いたり閉じたりする) |
| マウスホイール | 拡大縮小 (PC で遊ぶとき) |

### アイコンボタン (画面下)

| ボタン | できること |
| --- | --- |
| ピンクの縁の模様 | 上のシートの模様をかえる (しましま → あみあみ → あまつぶ → なみのわ → おはな) |
| 水色の縁の模様 | 下のシートの模様をかえる |
| 3色の円 | 色のセットをかえる (レースカーテン / いろみず / いちごミルク / にじ / よるのまど) |
| 太陽 | 光を当てる。指のあとを暖かい光がついてくる |
| 霧吹き | 水滴をまく。水滴は明るい線の上に来るとキラッと光る |
| 矢印 (左右) | 押している間、シートがくるくる回る |

### かくし要素 (状態のつながり)

- 模様の**明るい山**には、いつも小さな光の粒がきらめきます。
- 霧吹きの**水滴**は、モアレの明るい線の上を通るときだけ強く光ります。
- 重なりの強い明るい場所を**勢いよく**なでると、花火のような粒がはじけます。

## 起動方法

ビルド不要・依存ライブラリなしの静的ページです。

- `index.html` をブラウザでそのまま開く (ダブルクリックで動きます)
- もしくはローカルサーバーで配信:

```bash
cd moire-lace-lab
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

タブレット (iPad など) での2本指操作がいちばん楽しく遊べます。

## しくみ (大人向け)

裏テーマは **モアレ模様・干渉縞・周期構造の重なり** です。

2枚のシートはそれぞれ正弦波の周期構造 (縞・網目・ドット・同心円・花) を持ち、
透過光として掛け算で合成しています。周波数 \(f_1 \approx f_2\) の2つの縞を重ねると

\[
\sin(2\pi f_1 x)\cdot\sin(2\pi f_2 x)
= \tfrac{1}{2}\bigl[\cos(2\pi(f_1-f_2)x) - \cos(2\pi(f_1+f_2)x)\bigr]
\]

となり、差の周波数 \(f_1 - f_2\) の **ゆっくりした大きなうなり (モアレ)** が現れます。
シートをわずかに回したり拡大縮小したりするだけで差の空間周波数ベクトルが大きく変わるため、
「ほんの少し動かすと画面全体の模様がぬるっと動く」体験になります。

粒子エフェクトは、細かい縞を半波長ずらした数点の平均で打ち消して
**うなりの包絡線 (大きな模様の明るさ)** を近似計算し、明るい場所にだけ出しています。

## 構成

```
moire-lace-lab/
├── index.html        エントリーポイント (静的ページ)
├── README.md
├── css/
│   └── style.css     見た目 (スプラッシュ・アイコンボタン)
└── js/
    ├── audio.js      WebAudio の小さな効果音 (音声ファイル不要)
    ├── sheets.js     シート状態と模様の数学 (JS 側の正)
    ├── gl-renderer.js WebGL シェーダー描画 (sheets.js と同一式)
    ├── particles.js  きらめき・水滴・花火の粒子
    ├── input.js      指ジェスチャー (ずらす・回す・つまむ)
    ├── ui.js         大きなアイコンボタン
    └── main.js       組み立てと描画ループ
```

## 動作環境

- WebGL 1.0 と Pointer Events が使えるモダンブラウザ (Chrome / Safari / Edge / Firefox)
- WebGL が使えない環境では、やさしいお詫びメッセージを表示します
