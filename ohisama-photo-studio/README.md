# おひさま しゃしんやさん — サイアノタイプ風ゲーム

4歳の子どもが iPad / iPhone（縦・横どちらでも）で遊べる、日光写真（サイアノタイプ）ごっこゲームです。
紙の上にものを並べて、おひさまに当てて、水でじゃぶじゃぶ洗うと——青い紙に白いかたちが浮かび上がります。

## あそびかた

1. **ならべる** — 画面下（横画面では右）のかごから、葉っぱ・星・ハート・リボン・貝殻・ティアラを紙の上へドラッグ。
   - 置いたものを**トンとタップ**すると、ぴたっと押さえられて輪郭がシャープになります（浮いたままだと、ふちがぼやけます）。
   - 紙の外へドラッグすると片づけられます。
2. **おひさまに当てる** — 右上のおひさまを**押している間だけ**感光します。紙がだんだん色濃く変わっていきます。
3. **みずで洗う** — バケツをタップして水場へ。紙を指でじゃぶじゃぶこすると、こすったところから青い像が現れます。
   - 洗い場のふち（紙の外）を左右にドラッグするとトレイが傾いて、青のムラが流れます。
4. **干す** — 洗濯ばさみのアイコンをタップ。物干しロープで乾くにつれて青が深まり、キラキラと完成！
   - 新しい紙のボタンで次の1枚へ。前の作品はロープに掛かったまま見守ってくれます（セッション中のみ）。

文字はほぼ使わず、次にすることは光るリングのヒントで示します。固定ヘッダー・フッターはなく全画面です。
常時表示アイコンは左上のミュートボタンのみ。

## 「わずかな入力差 → 出力差」の実装対応

| 入力差 | 出力差 | 実装 |
| --- | --- | --- |
| 太陽に当てる時間が短い | 薄い水色 | 露光量をピクセル単位で蓄積し、露光→青の色ランプで変換 |
| 長すぎる | 全体が濃すぎる | 物も光を7%透過するので、長時間で白部分までカブる |
| 物が少し浮いている | ふちがぼやける | 置いた直後は lift 値を持ち、マスクをぼかして合成（タップで密着） |
| 水で洗いすぎる | ちょっと薄くなる | 洗い量が飽和した後もこすると overwash が増え、青が退色 |
| 紙（トレイ）を傾ける | 青のムラが流れる | 露光の濃い点からストリーク粒子が流れ、半透明の筋を焼き込む |
| 途中で雲が来る | まだら模様になる | 雲の影が局所的に露光を遮り、ムラとして残る |

どの結果も「失敗」扱いはせず、そのまま作品として完成します（バツ印・失敗音などのネガティブ表現なし）。

さらに本物らしさとして：葉っぱの葉脈やティアラの宝石・リボンの布・貝殻の溝は光を通しやすく、
白いシルエットの中に青い模様として写ります。乾くと青が深まるのもサイアノタイプの実際の挙動です。

## 動かしかた

ビルド不要です。`index.html` をブラウザで開くだけで動きます。

- ローカルで: このフォルダで `python3 -m http.server` などを起動して `http://localhost:8000/` を開く（file:// 直接でも動作します）
- iPad/iPhone: Safari で開き、「ホーム画面に追加」すると全画面で遊べます

音（効果音とオルゴール風BGM）はすべて Web Audio でその場で合成しており、音声ファイルはありません。
左上のスピーカーでミュートできます。

## 構成

```
ohisama-photo-studio/
├── index.html          エントリポイント
├── css/style.css       全画面・タッチ最適化
└── js/
    ├── util.js         数学・色・LUTヘルパー
    ├── audio.js        効果音とBGM（Web Audio合成）
    ├── shapes.js       置く物6種とアイコンのベクター描画
    ├── paper.js        感光・水洗シミュレーション（Sheet クラス）
    ├── scene_title.js  タイトル
    ├── scene_table.js  ならべる＆露光
    ├── scene_wash.js   水洗い
    ├── scene_dry.js    乾燥・完成
    └── main.js         ループ・シーン管理・入力
```

対象環境: iOS/iPadOS Safari、モバイル/デスクトップの Chrome・Edge（Canvas 2D と Pointer Events を使用）。
